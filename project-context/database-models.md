# User Collection

## Purpose

Represents a Telegram user.

Users are automatically created when they interact with the bot for the first time.

Telegram acts as the identity provider.

No passwords are stored.

---

## Schema

```ts id="8lyc83"
{
  telegramId: string;

  username?: string;

  firstName?: string;

  lastName?: string;

  credits: number;

  plan: "free" | "premium";
}
```

---

## Example

```json id="8nqlh7"
{
  "_id": "...",
  "telegramId": "123456789",
  "username": "ajit",
  "firstName": "Ajit",
  "lastName": "Kumar",
  "credits": 10,
  "plan": "free"
}
```

---

## Indexes

```ts id="0a7hrc"
telegramId: unique
```

---

## Business Rules

### User Creation

When a new Telegram user interacts:

```ts id="wk4u53"
credits = 10
plan = "free"
```

---

### Credit Deduction

Every accepted analysis request consumes:

```text id="0r7tqb"
1 credit
```

Credit is deducted before job creation.

---

### Credit Reset

Cron job runs:

```text id="t08e7c"
0 0 * * *
```

and resets all users:

```ts id="kngfxj"
credits = 10
```

# AnalysisJob Collection

## Purpose

Tracks every analysis request submitted by users.

Acts as the source of truth for processing state.

---

## Schema

```ts id="47phkz"
{
  userId: ObjectId;

  type:
    | "url"
    | "pdf"
    | "document"
    | "zip"
    | "apk";

  status:
    | "queued"
    | "processing"
    | "completed"
    | "failed";

  displayName?: string;

  originalFileName?: string;

  telegramFileId?: string;

  inputValue?: string;

  errorMessage?: string;
}
```

---

## Field Explanation

### userId

References:

```text id="n8lbg0"
User
```

collection.

---

### type

Determines which worker should process the job.

Examples:

```text id="4ho8w6"
url
pdf
document
zip
apk
```

---

### status

Possible values:

```text id="cb09xk"
queued
processing
completed
failed
```

---

### displayName

Used for:

```text id="c7f4e7"
/history
```

response.

Examples:

```text id="blnkgq"
banking.apk

invoice.pdf

example.com
```

---

### telegramFileId

Stores Telegram file identifier.

Used only during processing.

Files are not retained permanently.

---

### inputValue

Used for URL submissions.

Example:

```text id="blln4r"
https://example.com
```

---

## URL Example

```json id="phjg3q"
{
  "userId": "...",
  "type": "url",
  "status": "completed",
  "displayName": "example.com",
  "inputValue": "https://example.com"
}
```

## APK Example

---

## Indexes

```ts id="sn4wl8"
userId

createdAt
```

# Report Collection

## Purpose

Stores final analysis reports.

Reports remain available even after uploaded files are deleted.

---

## Schema

```ts id="kzvk0y"
{
  jobId: ObjectId;

  riskScore: number;

  summary: string;

  findings: any[];

  reportData: any;

  aiProvider: string;

  aiModelVersion: string;
}
```

---

## Field Explanation

### jobId

References:

```text id="04o29y"
AnalysisJob
```

---

### riskScore

Range:

```text id="90m5zn"
0 - 100
```

Examples:

```text id="m03a2e"
0-25   Low Risk

26-50  Medium Risk

51-75  High Risk

76-100 Critical Risk
```

---

### summary

Human-readable explanation generated by Gemini.

---

### findings

Structured findings generated by workers.

Example:

```json id="8a7x6u"
[
  {
    "severity": "high",
    "title": "READ_SMS Permission"
  }
]
```

---

### reportData

Raw analysis output.

Examples:

* URLs
* Permissions
* Metadata
* Activities
* Redirect chains

---

### aiProvider

Example:

```text id="0lyl4m"
gemini
```

---

### aiModelVersion

Example:

```text id="4slq0u"
gemini-2.5-flash
```

---

## Example

```json id="m1h5wa"
{
  "jobId": "...",
  "riskScore": 72,
  "summary": "Application requests access to SMS messages and precise location.",
  "findings": [],
  "reportData": {},
  "aiProvider": "gemini",
  "aiModelVersion": "gemini-2.5-flash"
}
```

---

## Indexes

```ts id="abjykm"
jobId
riskScore
createdAt
```

# SandboxSession Collection

## Purpose

Used in Phase 6.

Tracks active APK streaming sessions.

---

## Schema

```ts id="4t3bg4"
{
  userId: ObjectId;

  jobId: ObjectId;

  containerId: string;

  sessionToken: string;

  expiresAt: Date;
```
